Definition of Done

« Ça compile » ≠ terminé.

  • Code poussé + branche dédiée
  • Pull Request ouverte
  • Review effectuée
  • Tests réalisés
  • Documentation ajoutée
  • Dispo en local / déployé
Organisation Git

Une feature = une branche.

main
└─ develop
   ├─ feature/xp-ranking
   ├─ feature/profile-system
   └─ fix/navbar-mobile
  • Commit à chaque modif (pas +5000 lignes)
  • PR à la main → review → merge
  • feat: / fix: / docs:

1 repo Mobile · 1 repo Web + Back
